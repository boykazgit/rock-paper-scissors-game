Rock Paper Scissors Game

This is a rock paper scissors game created with html, css and javascript .
It is a project as part of The Odin Project.

This project is the first I did implementing the saying "code explains your comments to the computer" and I can say its very true.
Thinking about code that way makes it a lot easier to write code and to get all your ideas down. 
It also allows you to determine where errors may come from.

The project was a good starting place to practice all I have learned from the Foundations course.

Concepts Implemented
- Functions
- Conditional Statements
- Loops

Later after progressing through the course and studying the DOM and events I added UI to the game as instructed by the course.
